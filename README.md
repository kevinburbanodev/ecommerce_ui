# Café Remite

A demo online store for an invented Colombian coffee shop, built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS v4**, **React Hook Form** and **Zod**.

Every coffee is a postage stamp drawn in code, the cart is the envelope it gets stuck on, and the finished order is cancelled with a postmark.

- Catalogue with a taste filter, product pages with grind selection, cart saved in `localStorage`
- Address form with validation that writes the envelope as you type
- Spanish and English, prices in Colombian pesos
- Checkout is UI only: no card fields, nothing is charged, sent or stored on a server

## Getting started

```bash
npm install
npm run dev
```

| Command | Description |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Type-check and build |
| `npm run lint` | ESLint |
